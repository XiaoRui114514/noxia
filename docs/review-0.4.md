# 0.4 专辑与列表修复

2026-11-08（UTC）。基线 `8aaa068`；开始时工作区干净。已读 AGENTS、README、当前列表、播放及存储代码；保留 Expo / React Native 架构，未新增依赖，未部署账号或数据库。

## 完成内容

- 旧列表按资料库遍历显示，顺序与 `resourceIds` 不一致；新界面按已加入顺序编号，已加入与可加入资料分开。加入为幂等操作，移除独立，上移/下移按最新状态定位目标，刷新保留顺序。保存列表的播放按显示顺序运行一次，避免受播放器临时随机和轮数影响。
- 单篇编排、原译文声音和语速使用草稿及明确保存，输入框临时清空不再写入 0；非法配置不落盘。仍兼容旧列表及单篇配置。
- 新增独立专辑：新建/命名/删除、曲目增删排序，原文与译文分别选择声音、0–20 遍、0.25–2 倍合成语速、句间间隔、1–20 轮、随机及循环。整篇模式为“原文全文重复→译文全文重复→下一篇”，逐句模式为“本句原文重复→本句译文重复→下一句”。随机以篇为单位，不拆乱原译文轮次。系统自动声音与播放器全局选声独立。
- 可将列表曲目和顺序复制为新专辑；原列表保留，专辑朗读设置使用默认值并可修改。未保存设置时禁止播放，显示保存/错误反馈。缺译文明确提示并跳过，空专辑与无可读内容拒绝播放；沿用 1000 步、15 万字符、8 小时准备限制。长课文保留独立句段，不拼成超长合成请求。
- 会话绑定专辑/列表身份及其设置，暂停/刷新恢复原时间线。修改所属集合会停止并清除旧会话，防止移除后仍读旧曲目；其他集合不受影响。修复 Web 句段自然切换后立即暂停时位置尚未更新的问题。
- 存储 schema 3；读取 schema 1/2，迁移前保存精确原始字节，schema 2 单独使用 `noxia.library.before-migration.v2`。专辑校验失败按条隔离并保留原文；整库备份包含专辑和许可确认。删除/恢复资料保留专辑中的位置，不回滚后来修改的专辑设置。
- 资源页删除常驻许可说明、复选按钮和许可入口；首次点击学习项目目录显示自适应弹窗，含固定版本的原许可链接。同意保存后才读取目录；取消/Escape 不发请求。许可版本与时间记在本机，刷新不重复弹出；导入资料保留来源和许可。
