## 已修复

1. 编辑、文件导入、生成稿和资源写入均经过 `validateResource`，读取也使用同一限制：标题 500 字符、原文/译文/解释各 10000 字符、2000 句段、总量 100 万字符。关键词数组累计字符数且统一限制 4000 字符。超限稿保留在编辑区，不写成非法资料。
2. 标题单改保留全部句段数据。未修改行、移动行及修改行尽量延续 ID；显式拆分/合并保留重点与段落、汇集解释和关键词。双语拆分要求人工对应。编辑前最近 20 个版本保留；编辑区显示保存状态，草稿刷新恢复，未保存时不打开另一篇覆盖草稿。
3. 同会话继续直接调用恢复；重建时间线时校验计划、上下文、资源、步骤 ID 和位置。整条原始编排持久保存，浏览器已验证列表第二篇刷新续播，换篇不套用旧秒数。过期或不同身份的标记不使用。
4. 模型配置恢复与主动换地址分开，重启保留已选模型；目录未就绪时生成按钮不可用。重点筛选使用 `undefined` 区分未筛选与空数组，空结果不播放全文。
5. 词典经过条数、长度、重复和格式检查后持久保存，显示保存结果；结构支持全局与单篇覆盖，但单篇覆盖的独立界面尚未开放。
6. 生成请求有任务身份、进行中去重和取消。编辑中的草稿不被晚返回覆盖，完成稿进入最近十次历史；草稿持久保存。缓存只在内存，不包含于同步。
7. 相对定时与绝对截止时间戳分开；音频准备后重新计算绝对剩余时间，到时不启动播放。传入取消信号仍有默认超时，覆盖语音请求和流式/非流式下载；停止后不接受晚返回。
8. 列表与历史提供共享协议转换和真实结构的后端契约测试。模板分页跟随游标，离线退出区分本地清理/远端撤销。批次捕获会话凭据，切号后不把后续请求发到新账号，预览导入前重新校验归属。

## 数据与本地新流程

- 存储 schema 2 沿用旧键 `noxia.library.v1`，迁移前将原始字节保存到 `noxia.library.before-migration`。资料、模板、列表或历史异常按条隔离；原文连同原因进入备份，不阻断合法条目。根格式损坏时只开放恢复入口，不自动覆盖原文。
- 设置提供整库 JSON 导出、导入预览、确认恢复及恢复点；替换前保存原库到 `noxia.library.before-restore`。Web 下载文件，原生使用文件与系统分享入口（原生分享尚需设备验收）。备份不含密钥或音频；导入当前限制 30 MB。
- 删除移入回收站；恢复保留资料 ID、列表位置和对应设置。版本恢复保留当前版；异常资料可查看原始 JSON、修复校验后恢复。
- 连续更新合并保存，避免每个状态立即序列化整库；错误可见，失败后可重试。全文搜索覆盖标题、作者、原文、译文、解释和关键词。资料、阅读和句段编辑分批呈现，尚未迁移到增量数据库。
- 本机复习：选择→回想→揭晓→核对原文/译文/解析→手动自评→提交→薄弱与到期记录→下一题；答题草稿和已提交步骤可刷新恢复。没有自动评分或模型判定，未有解析时如实显示缺失；播放完成不更新自评。

## UI

- 账号状态卡片与居中、自适应登录弹窗分离；未部署显示不可用，Web 不发送密码。Escape 关闭、焦点返回入口，系统键盘快捷键不穿透弹窗。
- 设置按账号、模型、外观、数据、关于组织并限制表单宽度。播放器缩小封面，突出标题/当前句/进度/主操作；队列和高级规则默认收起。
- 阅读原文保持清晰对比，译文用次级层级，当前句有边线；可暂停跟随。文稿有新建/编辑和保存状态；编排按类型显示适用参数。声音增加词典保存反馈；缓存展示总占用、已准备篇目及清理影响，清理需第二次点击确认。
- 切页回到顶部，修复上一页滚动位置导致标题被裁掉的问题。延续黑白和中性灰，保留现有导航/浮层玻璃及系统减少透明度、减少动态设置。

## 尚未完成或依赖外部条件

- Linux 无 Xcode，本轮未构建 0.3 IPA、运行 iOS 模拟器或验收实体设备。新增 Swift 准备进度字段、系统语音缓存、原生分享、锁屏/耳机/中断、原生大字体与读屏仍需 Mac 和设备；历史 0.2 构建不作替代。
- 移动账号门禁继续关闭；完整账号资料/缓存隔离、离线待传、增量更新、删除传播、限流重试、设备撤销与冲突比较未完成。真实认证和 Service Binding 需 staging 及发布约束中的生产备份/批准。
- 缓存只有总清理和已准备记录，无配额、逐篇删除或音频导出；“已准备”记录不等于独立断网验收。
- PDF/OCR/EPUB/Word、系统分享导入、流式模型、录音/识别、端侧模型、Android 原生音频、平台扩展及其他候选仍在后续阶段，不记为本轮完成。外部模型/声音的实连质量需用户自己的服务和授权。
