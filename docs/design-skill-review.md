## 具体安全边界

- `snapshot.mjs` 启动浏览器访问传入 URL，读取页面及其外部样式/图像，保存 HTML 和截图。访问私人站点会把私人内容写入输出；不能用于带有个人学习数据、账号或密钥的页面。
- `story.mjs` 读取输入 HTML，启动绑定 127.0.0.1 的本地文件服务，调用 Playwright、ffmpeg，并删除/重建输入目录下的 `.story-frames`。本地服务的路径判断使用字符串前缀，不应把它当作安全文件隔离；不要在含敏感文件的目录运行。
- 未发现脚本主动读取 API Key/环境密钥或固定向作者端点上传项目文件的代码。但快照会请求页面第三方资源，任意 HTML 本身也会发起请求；这不是完整安全保证。
- Skill 的付费图像生成和连接外部 MCP 提示不适用于 Noxia 基础设计。此次不启动付费生成，不安装额外外部连接。
- 如将来安装，固定已审查 commit，仅复制需要的 Markdown，不安装或执行 scripts；升级需重新审阅，不执行仓库内远程命令建议。

## 适用方式

可以借鉴其“先看真实画面、再检查间距/颜色/图标/文案/字体/布局/细节/动效”的审阅顺序。上游主要面向 Web，32–36px 导航行、网页字体、hero 视觉、hover 规则不能直接变成 iPad 设计标准。Noxia 应采用系统字体、至少44pt触控目标、动态字体、VoiceOver、分屏与系统 Reduce Motion。

上游 SKILL 第4步要求先给方向并等待，且明确允许 “Skip the wait only when the user already said to just do it.” 用户本次已明确要求自主执行设计与开发，因此不因该文档反复请求同一设计确认。此处审阅不激活第三方脚本或外部服务。

建议 Noxia 方向：供学习者反复听读的安静阅读空间；性格为温和、准确、沉静；系统中性色与墨绿点缀；丰富度只落在作品封面与当前句；签名细节是表示“听读—留白—回忆”节奏的分段轨迹。避免营销 hero、AI 星星、紫蓝渐变、全屏发光、所有元素卡片化。

## 交付视觉审阅标准

这些是后续验收标准，**不是已经通过的截图测试**：

1. iPad 横屏为真正的侧栏与双栏播放器；竖屏/分屏按可用宽度重排，文字不截断、主控件不消失。
2. 正文与同步高亮可以阅读完整句；不要用低对比透明文字表现当前学习内容。
3. 保持4pt间距节奏、清晰层次和单一语义强调色；控件至少44pt，正文随系统字体变化。
4. 播放/暂停、队列、停顿和睡眠截止均有可读状态；离线准备与失败提示不伪装成已完成。
5. 浅色、深色、分屏和大字体截图逐项审看；用屏幕阅读器与键盘检查焦点和标签。
6. 动画只服务于播放器展开、状态切换和排序；Reduce Motion 下去除空间大幅移动与持续动画。
7. 不因运行一次 Skill 就宣称设计优秀；最终需人工按真实画面调整。
