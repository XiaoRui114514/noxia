# 自由编排引擎

`src/core` 是不依赖 UI、网络和音频框架的 TypeScript 引擎。`compile(resource, template, options)` 返回独立 `speech` / `silence` 单元，每个单元保留句段 ID、语速、声音和音量，原生播放器负责合成、缓存及调度。重复不会拼接原文或改变缓存身份。留白自背和静音停顿都编译为真实静音音频，不打开麦克风。

模板应用范围：

- `sentence`：对资源中已确认对应的每个句段重复应用模板。
- `paragraph`：仅合并相邻且具有相同显式 `paragraph` 编号的句段。缺失编号时按单个句段处理并给出警告。
- `document`：对所选全文应用一次模板。单次朗读上限 10000 字符，较长材料应使用逐句或按段范围。

`nextSentence` 和 `nextParagraph` 是终结本轮模板的控制步骤，必须放在最后一个启用步骤，重复次数固定为 1。`nextSentence` 前进到本轮已读范围后的下一句；按段范围则前进到下一段的第一句。`nextParagraph` 跳过当前段剩余句子；缺少段落信息时降级为下一句并警告。模板结束默认也前进到下一范围，因此一般模板无需显式导航。全文范围不接受导航控制。该规则避免导航后步骤被悄悄跳过，编辑器会收到明确错误。

选择句子通过稳定 ID 进行，并保持材料原始顺序；传入已删除 ID 会报错。缺少译文、解释或关键词只跳过对应空项并产生 `warnings`，绝不通过切标点、翻译生成或猜测建立对应。资源适配层负责提供可信的对应关系。

`validateTemplate` / `parseTemplate` / `exportTemplate` 对导入对象进行白名单复制和边界检查。最多 64 个模板步骤，每步重复 1–20 次，语速 0.25–2，音量 0–1。启用的留白 / 停顿为 50–600000 毫秒；朗读步骤及已关闭停顿的 `durationMs` 可以是 0。编译计划最多 1000 步、15 万朗读字符、8 小时静音，单次朗读最多 10000 字符；这些限制与原生模块一致并集中声明在 `AUDIO_LIMITS`，超限明确报错，不静默截断。JavaScript 按 UTF-16 长度计数，比 Swift 字形计数更保守。合成后的实际完整音轨仍由原生层检查总时长 8 小时上限，因为文字长度不能准确预测语音时长。

`canonicalSpeechCacheKey` 返回待 SHA-256 的规范字符串，包含文字、provider、模型和版本、声音、语言、语速、音量、音调、发音字典和音频格式。调用方必须使用合成后端真实版本，并在原生缓存中遵守同等规则。重复次数不属于合成参数。同一音频可以在计划内出现多次，缓存只生成一次。该函数本身不访问文件或保存私人文字。

测试覆盖顺序、重复、留白、分段、显式导航、缺失对应、声音覆盖、边界及恶意导入、缓存失效。原生播放是否正确执行这些单元仍需要独立 iPad 验证。
