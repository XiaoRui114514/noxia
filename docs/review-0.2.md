# 0.2 复查

2026-11-07。检查源码、协议、密钥流向、浏览器交互和实际构建。没有把模拟器或协议桩当作真机、真实服务验收。

| 问题 | 本轮处理 |
|---|---|
| 默认绑定某家公司，用户手填模型 | 使用兼容协议；自动目录、搜索选择，移除品牌默认值与手填 ID |
| 换服务可能发送旧密钥，旧响应覆盖新目录 | 密钥按地址隔离；取消与版本检查；目录缓存不含明文密钥 |
| 侧栏在窄窗占位，旧抽屉拦截内容 | 空间/比例/字体共同判断；手动收起；独立 Modal、遮罩、Escape、旋转关闭 |
| 口号、重复说明、字面量换行 | 删除口号；短标题与按钮；把文案偏好写进 AGENTS.md |
| 绿色配色与视觉层级 | 黑白灰；正文实底；导航与浮层用原生玻璃/模糊降级 |
| 账号位置靠下，需要填地址 | 「账号登录」置顶；固定构建配置；服务未部署时明确不可用 |
| 切号或退出期间的旧同步响应 | 核对 token/账号/来源快照；旧退出不会删除新会话 |
| 声音少，所有语音反复生成 | 系统筛选；兼容 TTS、发送确认、原生 MP3 缓存、失败回退 |
| 长文本与 Unicode 越界 | UTF-16 限额分块且不拆代理对；保留句段关联 |
| 云语音失败重复应用读音替换 | 回退使用原始文字，替换规则只执行一次 |
| 停止准备后晚到请求重新播放 | 操作代次与取消信号共同校验，试听和正常播放使用相同约束 |
| Web 勾选/选中状态未向读屏暴露 | 原生 state 与 Web ARIA 同时设置并加入交互回归 |

下一批优先事项：

1. 完成移动账号服务的备份、staging 和兼容验证后部署。不能只隐藏地址就声称账号能用。
2. 增加本机备份、恢复、缓存上限和逐项清理，解决长期资料保留与空间占用。
3. 保存整个播放会话与原生后台历史，恢复时保留队列、条目模板与相对进度。
4. 在真实设备验证锁屏、留白期间后台、睡眠截止、耳机与中断，以及系统玻璃的清晰度和性能。

尚未接入第三方模型或声音账号，也没有使用真实私人资料测试。
